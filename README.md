# Практика 2, задание 2: комплексный ремонт скважины


**Составной обработчик сообщений (Composed Message Processor)** = Разделитель + Маршрутизатор + Агрегатор.

Заявка на комплексный ремонт содержит несколько видов работ (бурение, электрика, логистика).
Её нужно разделить, отправить каждую часть своему исполнителю и собрать расчёты в одну смету.

## Схема

```
Инициатор -> [repair.requests] -> Разделитель -> [repair.parts] -> Маршрутизатор
   -> обменник repair.works (direct) -> [works.drilling] [works.electrical] [works.logistics]
   -> Исполнители -> [repair.estimates] -> Агрегатор -> [repair.summary] -> Инициатор
```

## Используемые паттерны

- Составной обработчик сообщений
- Разделитель (Splitter)
- Маршрутизатор по содержимому (Content-Based Router, direct-обменник)
- Агрегатор (Aggregator)
- Коррелляционный идентификатор (CorrelationId = id заявки)
- Адрес возврата (ReplyTo): Агрегатор отправляет смету в очередь, указанную инициатором
- Точка-точка: очереди с подтверждением (ack), prefetch=1, durable/persistent


Management UI: http://localhost:15672 (guest / guest).

## Ограничение

Если один из исполнителей недоступен, Агрегатор не получит все расчёты и смета не будет сформирована.
Решение — таймаут ожидания в Агрегаторе (в работе не реализован).
